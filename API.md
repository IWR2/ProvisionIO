# Data Model

The application manages two primary business entities—**Clients** and **Services**—stored in a **Single-Table Design** within **AWS DynamoDB**. User identity is managed and verified externally via **Auth0**.
* **Storage Strategy:** All entities (Clients, Services, and global/user Metrics) reside in a single table, differentiated by `EntityType` and `EntityId` attributes.

	- **Clients:** `EntityType: "CLIENT"` | `EntityId` prefix: `CLIENT#`
    
	- **Services:** `EntityType: "SERVICE"` | `EntityId` prefix: `SERVICE#`
    
	- **Statistics:** Records like `CLIENT_COUNT` and `SERVICE_COUNT` track totals via atomic transactions.*
## User

| **Property** | **Data Type** | **Notes**                                                                            |
| ------------ | ------------- | ------------------------------------------------------------------------------------ |
| id           | string        | The unique `user_id` assigned by Auth0 upon registration. (e.g., auth0&#124;123456). |

### Relationships

* **1:M relationship with Clients:** A User can be associated with 0 or multiple Clients.
* **Ownership:** A Client must have one assigned `owner` (the `user_id` of the Auth0 user).
### User (Managed by Auth0)

Users are not stored in the database. Instead, user identity is verified via JWTs provided by Auth0.

## Clients

| **Property**    | **Data Type**            | **Notes**                                                                                                           |
| --------------- | ------------------------ | ------------------------------------------------------------------------------------------------------------------- |
| id              | string                   | Unique UUID generated by the backend (e.g., `e1622f97-f6dd...`).                                                    |
| name            | string                   | The client’s name.                                                                                                  |
| contact_manager | string                   | The client’s contact manager.                                                                                       |
| email           | string                   | The client’s email. The value must be in email format.                                                              |
| array           | array of service objects | If a client has any services, then it is the array of service objects containing its ID. Otherwise, an empty array. |
| owner           | string                   | If the client has an assigned owner, then it is the ID value of its assigned owner. (e.g., auth0&#124;123456).      |
| self            | string                   | The self link of the client.                                                                                        |

### Relationships

* **User-Client Relationship:** M:1. A User (from Auth0) can own 0 or many Clients. A Client must have exactly one Owner.
* **Client-Service Relationship:** 1:M. A Client can have 0 or many Services. A Service can be associated with 0 or 1 Client.
* **Ownership:** Clients are linked to Auth0 users via an `owner` attribute, which maps directly to the user's Auth0 `sub` (subject) ID.
* **Assignments:** Services are linked to Clients via the `client` attribute. Assignments are protected by atomic `ConditionExpression` checks in DynamoDB to ensure a service cannot be overwritten while already assigned. The API enforces strict ownership checks; a service can only be assigned to a client if the requesting user owns that client.
## Services

| **Property** | **Data Type** | **Notes**                                                        |
| ------------ | ------------- | ---------------------------------------------------------------- |
| id           | string        | Unique UUID generated by the backend (e.g., `e1622f97-f6dd...`). |
| name         | string        | The name of the service.                                         |
| type         | string        | The type of the service.                                         |
| price        | float         | The monthly cost in USD; must be non-negative.                   |
| client       | string        | The UUID of the assigned client, or `null`.                      |
| self         | string        | The self-referencing API link.                                   |

### Relationships

* **Service-Client Relationship:** Many-to-One (M:1). A Service can be associated with at most one Client; a Client can have zero or multiple Services.
* **Assignments:** Services are linked to Clients via the `client` attribute. Assignments are protected by atomic `ConditionExpression` checks in DynamoDB to ensure a service cannot be overwritten while already assigned. The API enforces strict ownership checks; a service can only be assigned to a client if the requesting user owns that client.

# Endpoints

## Admin Endpoints

| **Endpoint**          | **Methods**             | Description                             |
| --------------------- | ----------------------- | --------------------------------------- |
| /init                 | POST                    | Create the DynamoDB table (Admin only). |
| /init                 | DELETE                  | Delete the DynamoDB table (Admin only). |
| /users                | GET                     | List all registered users (Admin only). |

## Clients

| **Endpoint**                             | **Methods** | Description                       |
| ---------------------------------------- | ----------- | --------------------------------- |
| /clients                                 | GET         | Retrieve all clients.             |
| /clients                                 | POST        | Create a new client.              |
| /clients/:client_id                      | GET         | Retrieve a specific client by ID. |
| /clients/:client_id                      | PUT         | Replace a specific client.        |
| /clients/:client_id                      | PATCH       | Update client details.            |
| /clients/:client_id                      | DELETE      | Delete a specific client.         |
| /clients/:client_id/services/:service_id | PUT         | Assign a service to a client.     |
| /clients/:client_id/services/:service_id | DELETE      | Unlink a service from a client.   |
## Services

| **Endpoint**          | **Methods** | Description                        |
| --------------------- | ----------- | ---------------------------------- |
| /services             | GET         | Retrieve all services.             |
| /services             | POST        | Create a new service.              |
| /services/:service_id | GET         | Retrieve a specific service by ID. |
| /services/:service_id | PUT         | Replace a service.                 |
| /services/:service_id | PATCH       | Update service details.            |
| /services/:service_id | DELETE      | Remove a service.                  |

## Other Endpoints

| **Endpoint**  | **Methods** | Description                       |
| ------------- | ----------- | --------------------------------- |
| /             | GET         | UI: API landing page / Status.    |
| /profile      | GET         | UI: Retrieve JWT for API usage.   |
| /protected    | GET         | Verify authentication.            |
| /debug-scopes | GET         | Debug JWT claims and permissions. |
